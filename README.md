# CANOPY
CANOPY is a Flutter-based habit and routine tracking application.
## Features
- Create, edit and delete habits.
- Track completed and missed habits.
- Flexible habit schedules.
- Habit reminders and missed-habit alerts.
- Statistics, activity heatmaps and streak tracking.
- Customizable icons, colors and fonts.
- Local data storage.
- Backup and restore functionality.
## Technologies
- Flutter and Dart
- Material 3
- Shared Preferences
- Flutter Local Notifications
- Timezone
## Run Locally
1. Install Flutter and Android development tools.
2. Clone this repository.
3. Run `flutter pub get`.
4. Run `flutter run`.
## Security
Signing credentials, private keys, local configuration and generated files must not be committed.
